ORBIT LIBRARY 1.3.1 - MAC

REQUIRES
macOS 13 Ventura or later. This universal application contains native
Apple Silicon (arm64) and Intel (x86_64) executables. No Python, Node.js,
or separate .NET installation is required.

START
1. Extract the ZIP and move Orbit Library.app to Applications.
2. Open it. The app starts fullscreen with a three-second Orbit intro.
3. Open System setup and choose a console, ROM folder, Mac emulator .app
   or executable, and launch arguments. Save, then Scan library.
4. Select a game and press Enter or Play.

The application is ad-hoc signed and is not Apple-notarized. macOS may
require you to approve the first launch in System Settings > Privacy &
Security > Open Anyway. Do not disable macOS security globally.

EMULATORS
Use Mac emulator applications. Windows .exe files and RetroArch .dll
cores do not run on macOS. RetroArch requires its installed Mac .dylib
core. Match the emulator/core architecture to your installed version.
Orbit launches the executable inside a selected emulator .app bundle.
Launch arguments and {rom}, {name}, {romdir} tokens work like Windows.
Close the emulator to return to Orbit. Games, BIOS/firmware, emulator
applications, and cores are not included.

NAVIGATION
Up: consoles; Down: games; Left/Right: move selection; Enter: confirm/play.
F: favorite; Command-K: search; Escape in search: clear and return.
F11 or Control-Command-F: fullscreen (some keyboards also need Fn).
Controllers paired with macOS: D-pad/stick navigates, A confirms/plays,
X favorites, shoulders change categories/systems, Menu toggles fullscreen.
The emulator handles controller input while a game runs.

LIBRARY AND ARTWORK
More > Import ROM folders recognizes system subfolders such as nes, snes,
psx, ps2, gc, and wii. Scans run in the background and preserve favorites.
Use More > Add game files for individual games. Use Set selected game
cover or place a same-name PNG/JPG beside a ROM. Logos remain transparent.
More > Animated background turns space scenery animation on or off.

Mac settings, favorites, and play history are saved in:
~/Library/Application Support/OrbitLibrary/library.json
Saves retain a backup; a corrupt library is preserved before recovery.
Unlike Windows portable mode, the data folder is outside the .app bundle
so moving or replacing the application does not replace your library.

More > Export/Import library JSON uses the same field format as Windows.
After moving a library across operating systems, assign Mac paths and
Mac emulator apps in System setup. Paths and emulator installations are
specific to each computer; Orbit does not move your game files.

VALIDATION
The release workflow compiles a universal app and runs native model,
launch-argument, filesystem, storage, and UI smoke checks on both Apple
Silicon and Intel macOS runners. A 10,000-game gallery is rendered in the
UI smoke check. See the repository's Actions run for results. Real games
and physical controllers still depend on your emulator and hardware.
